2. 문체 설정 톤

내 말투 예시 붙여넣기 (선택, 정확도가 훨씬 올라가요)

3. 사진 & 메모

사진을 여기로 끌어다 놓거나 클릭해서 선택하세요 (여러 장 가능)

4. 비밀번호 필수

API 키 같은 건 몰라도 돼요. 관리자(운영자)가 알려준 비밀번호만 입력하면 됩니다.

5. 완성된 초안

이 도구는 초안만 만들어줍니다. 사진과 완성된 글은 네이버 블로그 글쓰기 화면에 직접 붙여넣어 주세요 (자동 업로드는 네이버 정책상 지원하지 않습니다).
